# 대사 연결과 고정 UI 개편

2026-09-24 · v0.2.1

인물이 새 사실을 전하고 상대가 그 사실에 반응하는 순서를 다시 썼다. 장면 제목 아래에는 장소·시점·현재 상황을 고정 영역으로 표시한다. 출발, 구조를 위한 회차 이후, 도착 후 식사 초대처럼 장면 안에서 상황이 전환되면 이 설명도 바뀐다. 행동 지문이 없는 대사도 같은 공간을 유지한다.

## 장면별 정보의 이동

| 장면 | 처음 각자가 아는 것 | 대화에서 공유되는 것과 다음 행동 |
|---|---|---|
| 출발 | 깃은 마을 쪽을 감시하고 목적지를 안다. 보일은 탑승 명단을 확인했다. 리벳은 차량을 점검했다. | 보일이 27명 탑승 완료를 알린다 → 깃이 국경의 피난민 수용 소식을 전한다 → 보일이 중간 검문소를 걱정한다 → 리벳이 차량 상태를 답한다 → 출발 후 깃이 추격대의 승선을 발견한다 → 무기·엔진·고철 수집 역할을 나눈다. 검문소를 넘으면 추격이 끝난다는 잘못된 약속은 제거했다. |
| 첫 조합 | 플레이어가 연결을 만들었고 리벳은 갑판에서 그것을 볼 수 있다. 운전석의 보일은 점검 이유를 모른다. | 보일의 질문에 리벳이 고장이 아닌 확인이라고 답한다. 도움을 받은 리벳이 엔진에 집중할 수 있게 됐다고 말하고, 깃에게는 상자를 잡아 달라고 부탁한다. 실제로 확인되지 않은 소음 감소·도면·성능 결과는 주장하지 않는다. 발생 시점이 선택에 따라 달라지므로 앞뒤의 특정 장면에 의존하지 않는다. |
| 첫 돌격 후 | 깃은 뒤쪽 적이 떨어진 것을 확인했다. 보일은 앞길과 자신의 공포를 안다. 리벳은 엔진을 확인한다. | 뒤와 앞의 상태를 교환한다 → 보일이 엔진 상태를 묻는다 → 리벳이 답한다 → 다음 돌격 대비 질문에 출구 방어를 제안한다 → 깃이 더 일찍 경고하겠다고 약속한다. 엔진에 실제 피해가 없던 판에서도 성립한다. |
| 검문소 이후 | 검문소 통과는 모두 안다. 보일은 바닥 이상을 느꼈지만 원인은 모른다. | 리벳이 고정쇠 문제를 확인하고 사람을 옮겨 달라고 한다 → 깃이 이동 완료를 알린다 → 필요한 재료와 장식의 재사용 불가를 설명한 뒤 깃이 내준다 → 수리 동작과 보일의 확인을 거쳐 승객을 다시 앉힌다. |
| 구조 | 보일만 길 아래 수레를 먼저 봤다. 깃은 위치를 찾은 뒤 사람들을 본다. 리벳은 당초 연료 계획을 안다. | 발견 → 위치 확인 → 회차 방법 → 연료 위험 → 짐을 버리자는 제안 → 위험을 알고도 돌아가는 결정. 이후 ‘잠시 뒤, 수레 옆에 댄 요새’라는 지문으로 시간·장소가 바뀌었음을 밝힌다. 깃의 탑승 완료 보고 후 다시 출발하고 비워진 갑판을 안내한다. |
| 협곡 이후 | 보일은 남은 연료량과 구조된 할머니의 말을 안다. 리벳은 남은 경로를 계산한다. 깃은 구조된 이들의 사과를 들었다. | 연료량을 알려 주고 남은 내리막·줄인 짐을 근거로 도달 가능성을 확인한다. 구조 결정을 함께 책임진다는 대화 뒤에 할머니의 식사 약속을 전한다. 앞에서 다루지 않은 배관 누수를 갑자기 고쳐 연료 문제를 해결하는 전개는 제거했다. |
| 마지막 관문 | 보일은 불빛을 봤지만 관문인지 확신하지 못한다. 리벳은 지도를 안다. 깃은 신호와 뒤쪽 감시를 맡는다. | 관문 확인 → 피난민 신호 → 수비대의 응답과 문이 열리는 것을 확인 → 마지막 추격 보고 → 바로 진입해도 되는지 보일이 묻는다 → 깃이 27+5=32명 탑승을 확인한다. 갑자기 시작하는 연설이나 이유 없는 인원 확인을 제거했다. |
| 도착 | 장면 설명과 깃의 보고로 관문 폐쇄와 추격 차단을 먼저 알린다. 보일은 아직 긴장을 풀지 못한다. | 정차 → 안전 확인에도 손을 놓지 못하는 보일 → 리벳이 바퀴 받침을 확인해 주고 함께 내려온다. 잠시 자리를 비웠던 깃이 취사장 소식을 가져온다 → 일손에 관한 질문에 자신이 한 일을 답한다 → 내일의 창틀 계획에 깃이 이유를 묻는다 → 돌아갈 집이 없는 이들의 임시 거처라는 답을 한다. |

짧은 전투 무전은 서로 다른 시점에 한 줄씩 출력되므로 이전 무전에 대한 답처럼 쓰지 않았다. 독자가 듣지 못한 농담이나 질문을 알고 있다고 가정하지 않는다.

뒤쪽 돌격의 예고는 뒤를 감시하는 깃에게 맡겼다. 보일의 열기 무전은 설치하지 않았을 수도 있는 화염 분사기를 전제로 삼지 않는다. 깃이 모자 장식을 내준 대사부터 초상화에서도 장식을 숨기고 이후 장면·저장 복원에서도 그 상태를 유지한다. 결말 요약과 짧은 무전도 ‘오늘은 쉬고 내일부터 고친다’는 대화의 결정에 맞췄다.

## UI와 검증

대사창 전체 높이, 상황 설명, 초상화, 이름, 행동 지문, 본문 시작점, 진행 표시, 다음 버튼의 영역을 분리해 고정한다. 마지막 대사의 버튼 문구가 바뀌어도 너비·높이는 유지한다. 작은 화면에서는 같은 구조의 고정된 모바일 배치를 사용한다.

`tools/browser-dialogue.mjs`는 모든 장면을 화면 크기별로 열어 위치와 잘림을 측정한다. 매 대사마다 새 버튼을 찾아 클릭하지 않고 첫 버튼 중심 좌표를 계속 클릭/터치해 진행한다. 이 검사는 문학적 자연스러움을 점수로 판정하지 않는다. 대사 자체는 위의 정보 전달·질문과 답·장면 전환 순서로 편집 검토했다.

- 8개 장면, 88개 대사를 320×480, 320×568, 390×844, 768×1024, 1280×720, 1440×1000, 844×390에서 검사했다. 총 616번의 동일 좌표 진행이 통과했고 글자 잘림·실행 오류가 없었다.
- 대화 중 초상화·이름·본문 시작점·다음 버튼 좌표, 대사창 크기를 비교했다. 마지막 버튼의 문구가 바뀌는 경우도 포함한다. 장면 설명의 갱신과 장식 양도 전후의 초상화 변화도 확인한다.
- 단위·전투 시나리오 16개와 정적 빌드 통과. 전투 수치와 시뮬레이션은 변경하지 않았다.
- 근거: `dialogue-layout.json`. 브라우저 검사는 Chrome과 터치 입력 모사이며 실물 모바일 기기 측정은 아니다.
